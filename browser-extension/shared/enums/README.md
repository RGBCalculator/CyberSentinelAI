# Shared Enums

This directory contains enumerated types and discrete status collections shared across the extension.

## Purpose & Scope

- Define discrete sets of values such as threat severity levels (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`), scan decision verdicts (`SAFE`, `SUSPICIOUS`, `MALICIOUS`), and messaging action codes.
- Enable type-safe and consistent status comparisons across popup, background, and content scripts.

> **Note**: Documentation only. No implementation logic is included in this architectural sprint.
